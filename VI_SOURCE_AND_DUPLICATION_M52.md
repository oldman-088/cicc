## Independent evidence adapter
`vi_evidence_ingestion.parse_source_evidence(raw, source=..., collected_at=..., provenance=..., origin=...)` accepts a bounded **single caller-supplied JSON record subset**, no network and no source authentication. NVD CVE objects/wrappers, OSV records, GitHub GHSA records and individual EPSS rows retain explicit source ID, CVEs/aliases, optional source-modified timestamp, collection time, SHA-256 of exact bytes and origin/provenance. Caller retains raw bytes; a digest is consistency metadata, not provenance authentication. NVD supplied CVSS vector/base-score/source are preserved individually, with numeric bounds only: vector validity, recomputation and conflict adjudication are not implemented. EPSS score is preserved as an exact decimal string and source score date; no prediction, score calibration, exposure or priority is inferred. Missing CVEs, CVSS and modified time remain unknown. Malformed CVE IDs, missing required identity, naive timestamps, invalid scores, duplicate keys and oversized payloads fail closed. `quality_observation` bridges NVD/OSV/GHSA only via explicitly supplied CVEs and SHA provenance; EPSS remains separate. This is not a provider API client, scheduler, approved shared source contract or authoritative finding.

`vi_asset_correlation.correlate_declared_asset_evidence` joins only caller-declared asset→inventory and inventory→CVE/component links; retains provenance, origin and separate collection ages; returns applicability/exposure `unknown`. No matching algorithm or negative finding is inferred. Tenant authorization and collection/storage retention remain caller/host responsibility.
