## Local versioned interfaces and errors

- `quality_json_for_version('cicc.vulnerability-quality/1', inventory, observations, consultations, as_of=..., max_observation_age=...)` returns deterministic canonical JSON equivalent to `quality_json`; unsupported version raises `ValueError`, never silently downgrades. Typed input requires caller-authorized `Inventory`, `Observation`, `Consultation`; aware time and explicit positive collection-age horizon; duplicate/dangling/malformed/inconsistent/budget-exceeding input fails validation. `quality_document` describes evidence, not authoritative applicability, safety or source truth. Collection times and source modification times retain different meanings. See `VULNERABILITY_QUALITY_CONTRACT.md`.
- `conflict_document(engine, origin=..., conflict_id=..., schema_version='cicc.kev-conflict-summary/1')` returns deterministic JSON-compatible, UTC-timestamped metadata/delta from read-only repeatable-read inspection. Unsupported version or invalid origin/ID raises `ValueError`; absent, corrupt or inconsistent stored evidence raises `SnapshotUnavailable`; database availability/permission errors remain database errors. Summary intentionally excludes raw streams; authorized operator-only `inspect_conflict` returns both verified originals. Different schema names distinguish the summary from Python `cicc.kev-conflict-inspection/1`, which includes catalog objects. Hashes establish consistency, not authenticity or admin-resistant integrity. Both functions are trusted-process interfaces, not tenant authorization mechanisms.
- `import_sbom` consumes bounded raw bytes and explicit document ID/provenance/aware collection time/origin. Returns `ImportedSBOM` including exact input SHA-256, format/version, normalized `Inventory`, sorted ignored field names and original license statements; the caller retains original bytes. `SBOMError` rejects invalid, oversized, ambiguous, unsupported version/structures and dangling references. Only restricted SPDX 2.3 JSON and CycloneDX 1.5 JSON subsets are supported (see `SBOM_IMPORT_CONTRACT.md`); this is not full standards validation. Completeness remains unknown; no vulnerability link is inferred.
- `prepare_resolution` is a **non-persistent draft planner**, not an authorized mutation interface. It checks explicitly supplied evidence references, rationale, expected hashes, decision time, history chain and an injected authorizer. `ResolutionDraftDenied` means its injected authorizer did not return literal `True`; `ResolutionDraftError` covers invalid input/history and idempotency conflict. A real host must obtain verified identity and permissions independently; injected callbacks, in-memory history and hash chains are not trusted audit. No winner or source promotion is supported.

Any future host adoption requires security review of permissions and input provenance, wire/body limits, transport error/redaction mapping, audit/trace coverage and per-tenant data access. No mapping above implies HTTP status or endpoint. Public KEV is global operator data; never rely on it to authorize tenant-scoped evidence or expose raw data blindly. Unsupported versions are rejected, not upgraded; new incompatible versions need owner-reviewed contracts and compatibility tests. Existing v1 names and semantics are independently versioned library contracts, not approved CICC shared APIs.
